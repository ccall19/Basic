# 常见和弦问题答疑

## 1. 三和弦真的“只有”三个音吗？（关于“重复音/Voicing”）
严格从乐理定义来说，“三和弦”确实只包含三种具有不同功能的音：**根音、三音、五音**（例如 C和弦就是 C - E - G）。

但是，在实际演奏中（不管是吉他扫弦还是钢琴伴奏），我们弹下的音往往**远多于三个**，这叫做**“重复音（Doubling）”**或**“和弦声部排列（Voicing）”**。

**关键规则：只要你弹下去的几把声音，全部落在这个三和弦的几个功能音内，它依然是那个三和弦。**

* **举例（钢琴大一统和弦弹法）**：
  你在钢琴上，左手在低音区按下两个 C（八度下），右手在中音区按下 C - E - G - C。一共响起了 6个键，但这 6个音全都是 C、E、G的各种翻版，没有出现第四种音名。所以**这仍然只是一个普通的三和弦（C大三和弦）**。
* **为什么要重复音？**
  * 增加厚度：一把吉他扫下 6根弦，虽然还是那 3个音名，但声音会像一堵墙一样丰满。
  * 安排旋律线：右手的最高音往往决定了上面那层隐隐约约的旋律感。

## 2. 和弦底下那个“比较低的音”是什么？怎么写？（斜杠和弦 / 转位与复合和弦）

你说的和弦下面带个比较低的音，在流行音乐中极为常见。这种记谱法叫做**斜杠和弦（Slash Chords）**，长相为：**`A / B`**。

### 如何阅读？
口诀：**左边是右手弹的（主和弦），右边是左手弹的（最低音/Bass音）。**
* 比如 **`C / E`** ，念作“C over E”。意思是你弹一个 C大三和弦（C-E-G），但是不管你用什么姿势弹，**最底下的那个低音（Bass音）必须是 E**。

这种写法主要用于两种情况：

#### 情况一：转位和弦（Inverted Chords）
底下的那个音，本身就包含在左边的和弦里。
* **原位**：如果直接写 `C`，潜规则是最底下就是根音C。
* **第一转位**：写成 **`C / E`**。和弦还是 C,E,G，但因为底层换成了三音E，声音听起来比原位更“飘”、“更有升力”。
* **第二转位**：写成 **`C / G`**。底下的音换成了五音G，有强烈的想停下来的稳重感。

> 为什么流行歌爱用转位？为了让贝斯线（Bass Line）更平滑。比如进行是 C → Am，贝斯的跳步很大；如果换成 C → C/B → Am，贝斯的走向就变成了平滑下楼梯的 C → B → A，非常顺耳。

#### 情况二：复合和弦 / 分裂和弦（Hybrid Chords / Polychords）
底下的那个音，**不属于**左边的三和弦！
* 比如 **`F / G`**。这是流行歌（尤其周杰伦等R&B、抒情歌）里最常用的“绝杀和弦”。
* 左边是 F大和弦（F-A-C），右边底下的根音是不相干的 G。
* 这个和弦融合了 F 的空灵和 G根音的牵引力，听起来有一种“城市高楼大厦中悬浮的现代感”。其实在高级乐理里，它可以被看作是一个省略了根音的 G11 和弦，但为了乐手好弹，就写成了极其直观的伪装版 `F / G`。
