# 基础音高 (Pitch)

在讨论“音程”和“和弦”之前，我们必须能准确呼叫每个按键的名字。如果把音乐比作画画，这就是最基础的颜色名称。

## 1. 音名 (Pitch Names，绝对音高)
**音名**是客观存在的物理频率的命名，不管在任何国家、不管你用什么乐器，它的名称和位置永远固定不变。
* **七个基本音名**：C、D、E、F、G、A、B。
* **为什么从C开始而不是A？** 因为由于历史演变原因，钢琴键盘上最中间、最常用的自然大调是以 C 开头的。我们通常称钢琴正中间的那个 C 为 **中央C (Middle C, 常标记为 C4)**。

## 2. 唱名 (Solfège，相对/绝对音高)
**唱名**是我们用喉咙唱出来的发音，方便记忆和演唱。
* 它们分别是：**Do, Re, Mi, Fa, Sol, La, Si (Ti)**
* **固定调唱名法**：永远把 C 叫作 Do，D 叫作 Re。
* **首调唱名法（非常重要）**：把一首歌的主音叫作 Do，比如到了 G大调，就把 G 唱作 Do。这在流行乐里最常用。数字简谱（1 2 3 4 5 6 7）通常也是基于首调记录的。

## 3. 变化音与“异名同音” (Accidentals)
基本的七个音（白键）之间并不是完全均等的（记得 E-F、B-C 之间是半音吗？）。为了填补全音之间的“缝隙”，我们引入了**黑键**。

因为白键的缝隙是共用的，所以**每一个黑键都有两个名字：**
* **升号 (#, Sharp)**：把一个音升高半个音。比如 C 和 D 中间的兄弟，可以叫它 **C#（升C）**。
* **降号 (b, Flat)**：把一个音降低半个音。还是同一个兄弟，相对于右边的D来说，它可以叫 **Db（降D）**。

> **💡 结论：** C# 和 Db 在钢琴上弹的是同一个按键，绝对音高一模一样，这在乐理中被称为**“异名同音”**。选用哪个名字，取决于接下来学到的**调号规则**。

## 4. 八度 (Octave)
当你从一个 C 往右弹，弹到下一个 C 的时候，听感上它们极其相似，但第二个 C 更高、更尖。
在物理学上，高八度的那个音的振动频率正好是低八度音的 **2倍**（例如：A4 = 440 Hz，A5 = 880 Hz）。
为了在编曲软件 (MIDI) 中区分它们，我们会加上数字：
* C3 属于偏低音/次低音区。
* C4（中央C） 是大部分人声好驾驭的中音起步。
* C5 是相对较高、偏明亮的女声音区。
