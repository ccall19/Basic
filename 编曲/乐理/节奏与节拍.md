# 节奏与节拍 (Rhythm)

节奏是音乐的“地基”和“心跳”，它决定了音乐在时间维度上是如何流动的。即使是没有固定音高的打击乐，只要有好的节奏，依然能引人入胜。

## 1. 速度 / BPM (Beats Per Minute)
BPM 是衡量音乐快慢的绝对指标。
* **定义**：每分钟包含的拍子数。
* **举例**：BPM = 60，表示一秒钟正好打一拍（和人类平静时的心率差不多）；BPM = 120 就是一秒钟打两拍，听起来相对欢快、有动感；EDM舞曲通常在 128 左右。

## 2. 拍号 (Time Signature)
拍号标志着一首曲子每个小节的“容量”和“分段方式”，写在谱子开头，比如常见的 4/4、3/4、6/8。
* **分母**：代表“以什么音符作为一拍”。（比如分母是4，就是以四分音符为一拍；分母是8，就是以八分音符为一拍）。
* **分子**：代表“每个小节里一共有几拍”。
  
**常见拍号及其听感**：
* **4/4 拍 (流行乐最常见)**：强、弱、次强、弱。（自带稳定、对称、向前的感觉）。
* **3/4 拍 (圆舞曲/华尔兹)**：强、弱、弱。（自带旋转感、“蹦-擦-擦”的三步舞感觉）。
* **6/8 拍**：虽然一个大节有6拍，但听感上常被分为两组“强弱弱、次强弱弱”的摇摆感。

## 3. 音符时值 (Note Values)
音符不仅有高低之分，更重要的是它“持续多久”。在最常见的 4/4 拍中：
* **全音符 (Whole Note)**：占据整个小节（4拍的长度）。
* **二分音符 (Half Note)**：全音符的一半（长度为 2拍）。
* **四分音符 (Quarter Note)**：一拍打一个音（长度为 1拍），这是最基础的参照物。
* **八分音符 (Eighth Note)**：一拍里打两个音（长度为 1/2拍）。
* **十六分音符 (Sixteenth Note)**：一拍里塞进四个音（长度为 1/4拍），编曲中常用来做细碎的Hi-hat（踩镲）或者快速的吉他扫弦。

## 4. 律动表现 (Groove)
一首歌如果所有的音符都死板地落在正拍上，会像机器人在念经。打破规律，就产生了律动（Groove）：
* **休止符 (Rest)**：此时不发声。“此时无声胜有声”，留白是让节奏呼吸的关键。
* **附点 (Dotted Note)**：在音符屁股后面加一个点，表示延长该音符自身一半的时值（比如附点四分音符 = 1拍 + 0.5拍 = 1.5拍）。常用来制造“瘸腿”跳跃感。
* **切分音 (Syncopation)**：改变重音原本的位置，把本该弱拍的音提前或延后到强拍位置，制造一种“被猛拉了一把”的动力和不平衡感，这是流行、爵士和R&B的灵魂。
