# 音程 (Interval)

音程是指两个音在音高上的距离。衡量这个距离，我们有两把“尺子”，缺一不可：一个是**“度数”**，一个是**“半音数”**。

## 1. 原理基础：半音与全音
* **半音**：音乐中最小的距离单位。在钢琴键盘上，任何紧挨着的两个键（包括黑键和白键）之间的距离就是半音。
* **全音**：2个半音 = 1个全音。

**自然音阶的“不均匀性”：**
在基本的七个自然音（C D E F G A B / Do Re Mi Fa Sol La Si）中，它们之间的距离并不是均匀的：
* **E(Mi) 和 F(Fa)** 之间只有 1个半音（它们中间没有黑键）。
* **B(Si) 和 C(Do)** 之间只有 1个半音（它们中间没有黑键）。
* 其余所有相邻的自然音之间，都有两个半音（一个全音）。

## 2. 什么是“度”？
度数是依靠“数基础音名”数出来的。
比如：
* C 到 C 本身，包含1个音名，叫“一度”。
* C 到 D，包含 C、D 两人，叫“二度”。
* C 到 E，包含 C、D、E 三人，叫“三度”。
* D 到 F，包含 D、E、F 三人，也叫“三度”。

## 3. 为什么同样是三度，包含的半音数量不同？
虽然**“度数”**能描述跨越了几个音名，但由于 E-F 和 B-C 之间是天然的“半音短区间（抄近道）”，导致同样跨越三个音名，底层的物理半音总数却可能不同。

* **C 到 E （大三度）**
  * 路线：C -(2个半音)- D -(2个半音)- E
  * 总计：包含 4 个半音。
  * 听感：明亮、开快。因为没有碰到 E-F 或 B-C 这样的天然窄口，全都是“全音”跨度，所以比较宽。

* **D 到 F （小三度）**
  * 路线：D -(2个半音)- E -(1个半音)- F
  * 总计：包含 3 个半音。
  * 听感：暗淡、柔和。因为跨域时碰巧经过了 E-F 这个“半音窄口”，所以总距离缩短了1个半音。

> **总结：** 度数只能表示字母的跨度宽窄步数，而加上“大”、“小”这样的前缀（如大三度、小三度），才能绝对精准地定义两个音不仅走了三步，而且实际相差几个半音的物理距离。
